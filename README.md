# The Conveyor Belt Sorter 🏭

A production-ready 2D educational web game platform built with **Astro**, **TypeScript**, and **Tailwind CSS**.

## Subjects
- 📝 English Grammar — Noun / Verb / Adjective
- 🧪 Science — Solid / Liquid / Gas
- 🏛️ Civics — Democracy / Monarchy / Dictatorship
- ⚗️ Chemistry — Acid / Base / Neutral Salt

## Development

```bash
npm install
npm run dev       # localhost:4321
npm run build     # production build
npm run preview   # preview build
```

## Architecture
- **Game Engine**: 60FPS requestAnimationFrame + delta-time, AABB collision
- **Audio**: Zero-asset Web Audio API procedural synth
- **Ads**: Zero-CLS pre-sized slots + H5 Games Ads shift-break hooks
- **SEO**: Static routes, JSON-LD structured data, crawlable curriculum guides
